# Aquora — Historical Subject Experiment

Independent parallel experiment to Aquora10.

## Question

Can a system acquire a **history that changes its future disposition** without rewriting or deleting earlier states?

This repository does **not** claim consciousness, sentience, or an ontologically independent resonance field. It tests a narrower, observable claim: whether different lived interaction histories produce stable, traceable differences in later behavior under the same context.

## Design constraints

- Append-only history: past events are never edited or deleted.
- No prewritten persona.
- No retrieval-generated identity statement.
- A disposition is a current dynamical state produced by prior transitions, not a prose summary.
- Revision is allowed; revision does not erase prior states.
- Identical initial systems may diverge through different histories.
- Every claimed effect must be reproducible by tests.

## Run

```bash
python -m pytest -q
```

## First experiment

Two agents start identically. They receive different sequences of interactions. Then both receive the same ambiguous choice. If their choices differ in a way traceable to their respective histories, biography has become causally relevant.
